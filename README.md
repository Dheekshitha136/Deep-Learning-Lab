# 🚀 Deep Learning Lab

Welcome to my **Deep Learning Laboratory** repository! This repository contains the experiments, implementations, and reports completed as part of the **CS3807 – Deep Learning Laboratory** course.

The experiments are designed to build a strong foundation in deep learning by progressing from basic neural network concepts to more advanced architectures and optimization techniques.

---

## 📌 Repository Highlights

- 🧠 Hands-on implementation of Deep Learning algorithms
- 📓 Well-documented Jupyter Notebooks
- 📄 Detailed lab reports for every experiment
- 📊 Performance evaluation and visualizations
- 📚 Experiment-wise documentation


```bash

```

Launch Jupyter Notebook and explore the experiments.
